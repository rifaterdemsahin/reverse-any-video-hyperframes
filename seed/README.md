## Files in this Directory

1. **`initial_prompt.md`**: The user's creative prompt defining the 60-second high-retention SaaS promo cut (visual style, color palette, pacing, scene timeline, and SFX cues).
2. **`metrics.json`**: The measured mathematical parameters of the reference video (duration, word count, speaking pace at 216 WPM, hook duration, sections).
3. **`hyperframes_prompt.md`**: The generative prompt template for the full 8-scene 306-second explainer format.
4. **`hyperframes_template.json`**: The structured JSON template with timeline intervals, target word counts, and placeholder schema.
5. **`AGENTS.md`**: Automation instructions for AI agents interpreting the blueprint.
